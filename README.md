# Personal Portfolio Website

This repository contains the source code for my personal website. It
serves as both a portfolio and a place to document my progress as a
developer.

## Overview

This version was rebuilt from the ground up. While I reused the
experience and lessons learned from previous iterations, the codebase
itself was redesigned to be cleaner, easier to maintain, and more
scalable.

The project combines a modern interface with a lightweight architecture
using only HTML, CSS, and vanilla JavaScript.

## Features

-   Spotify-inspired project viewer
-   Responsive design
-   Custom cyber-inspired interface
-   Animated UI elements
-   Automatic GitHub repository integration
-   Social links
-   Lightweight, dependency-free frontend

## GitHub Integration

One of the biggest improvements is the Projects page.

Instead of manually adding every project to the HTML, the website
fetches my public GitHub repositories using JavaScript and displays them
automatically. This keeps the portfolio synchronized with my GitHub
while making future updates much easier.

## Development

Building this version took approximately four hours of development and
another two hours of debugging, testing, and refining the design.

During development I used:

-   HTML5
-   CSS3
-   JavaScript (Vanilla)
-   GitHub API
-   Figma

Special thanks to GitHub for providing access to the GitHub Student
Developer Pack, which included premium Figma resources used during
development.
